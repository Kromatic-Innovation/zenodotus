# Contributing to gridcalc

Thanks for your interest. `gridcalc` is deliberately small, so the process is
short.

1. Open an issue describing the change before a large PR, so we can agree it fits
   the scope (small, dependency-free, grid helpers).
2. Add or update tests for anything you change. `pytest -q` must pass.
3. Keep the public API minimal and dependency-free — standard library only.

By contributing you agree that your work is released under the project's MIT
License.
